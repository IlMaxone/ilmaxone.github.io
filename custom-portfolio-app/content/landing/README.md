# Struttura editoriale della landing

Ogni cartella di questo livello genera un pianeta nella landing, una voce nel menu e una pagina `/universo/<nome-cartella>`.

Ogni file JSON contenuto nella cartella genera invece un pianeta nella pagina della sezione. I nomi che iniziano con `_` sono ignorati e possono essere usati per template o appunti.

La guida completa è in `../../../docs/content-system.md`.
